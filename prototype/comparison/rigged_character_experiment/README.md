# R2：原 A 房间中的单角色坐姿打字骨骼实验

2026-09-25。实机对照页：[index.html](index.html)。R0 原 A 与 R1 静态坐姿仍保留在[上一轮实验](../character_experiment/README.md)；R2 只替换 R1 的电脑坐姿人物，原 A 相机 FOV 45°、光照、房间、桌椅、UI 和虚构任务均不改。R1 的站姿 idle 仍沿用，R2 从用户点“开始”的演示状态切入。此实验不写入真实目标、任务完成或学习成果。

## 可编辑资产与实际运行

`build_rigged_character.py` 打开同仓原创 R1 的 `.blend`，为坐姿网格新增两手各两根短手指，然后制作 8 骨 armature（髋、脊柱、左右上臂/前臂/手）和 8 个显式顶点组。分立网格烘焙原倒角/法线并合成单一 skinned mesh；各部件使用刚性权重，因此这是最小可验的绑定，**不是**完整的人体平滑蒙皮。`adult_student_rigged.blend` 留有 armature、网格、权重组、两段 action，可在 Blender 编辑。源、GLB 与生成脚本均为本仓原创，沿用 MIT；没有下载角色、动作、贴图或付费调用。

GLB 实际含 1 skin、8 joints、2 animations：`SitToType`（0.6 秒，已经坐着的人稍作前倾/落座）及 `TypingLoop`（1.2 秒，双手交替移动）。Godot **4.7.stable Compatibility** 实际导入后，在场景里读到 `Skeleton3D` 8 根骨和两段动画，由用户开始演示任务触发前段，然后循环后段。短视频为 Godot 真实窗口逐帧录制后编码的 H.264；不是 Blender 预览或人工合成动效。

## 复现

在仓库根目录运行：

```sh
blender --background --python prototype/comparison/rigged_character_experiment/build_rigged_character.py
/Applications/Godot.app/Contents/MacOS/Godot --headless --editor --import --path prototype/godot
python3 prototype/comparison/rigged_character_experiment/run_capture.py
```

最后一步需要图形桌面和 `ffmpeg`，依次采 360×320、1280×720 的昼/夜场景，各 9 个 `SitToType`/`TypingLoop` 实际 Godot 帧，并编码 360×320 白天的 3.0 秒短录屏。高分屏输出为 2× 物理像素；小窗审图请按 360 CSS 像素观看，不能把 720 像素位图放大来宣称可读。脚本验证 Godot 导入日志、8 骨/2 动画/循环设置、关键帧尺寸及素材 SHA；错误日志或缺帧会失败。参数与各文件 hash 见 [manifest.json](manifest.json)，日志里的本机绝对仓库路径已脱敏。

## 接点与变形审查

- **双手与键盘**：键盘范围 X −1.295 至 −0.345、Z −1.43 至 −1.15，顶面 Y 1.2975。Godot 关键帧记录的两腕 X 约 −1.234 至 −0.526、Z 约 −1.29 至 −1.247，始终落在键盘水平投影内。原创手指静姿底面约 Y 1.306，与键盘顶面差约 0.009 个世界单位；动作中会移动，未做网格碰撞/逐帧无穿透证明。**可说手到键盘附近，不能说精准键位接触已验收。**
- **髋与椅**：椅面顶面 Y 0.84；人物坐姿髋部球体中心 Y 0.78、半径 0.17，约 0.23 单位侵入椅面。渲染可看作被坐垫遮住，但真实几何支撑与衣服变形尚未解决。`SitToType` 从已坐姿开始，只是轻微落座/前倾，**不是站立到坐下的完整动作**。
- **脚与地**：两鞋底静姿最低点约 Y 0.007，高于地面约 0.007；坐姿收尾在视觉上接地。过渡起始髋骨上抬 0.07，双腿作为刚性子部件可能短暂离地，这需要下一轮更合适的腿骨/逆运动学。
- **肩肘/权重**：原 R1 分件使用每顶点单骨权重，Godot 确实驱动它们，前臂在全窗图可见交替；肘部与袖口存在接缝，不能算高质量皮肤变形。
- **实际大小可读性**：全窗能看出左右手交替与人朝电脑；360×320 小窗中人物仍约 23×29 逻辑像素，坐在电脑前可辨，单手敲键盘的细节很弱。R2 是动作管线与接点口径验证，**未跨过用户要求的角色精美门槛**；不据此改变 A 基线或美术路线。
