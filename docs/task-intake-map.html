TASK INTAKE / 01–06 / PROPOSED WORKFLOW

先把自己的事情说清楚

每轮只问 1–3 个问题，先自由讲述，再查漏与校正。允许以后补充，先开始一件事。

从原话到自己的本地任务卡

以下为虚构示例，展示字段和来源；本人确认后才保存为当前安排。

来源片段任务卡字段保留的未知
“考试大概下个月。”任务：考试准备；期限：估计具体日期、范围待核实
“我答应周五给同学反馈。”类型：对外承诺；来源：本人自述对应日历日期待确认
“每天能稳定用一小时。”稳定预算：每日一小时已占用安排仍要核对
当前交付：访谈协议、模板与提示词。待验证：不同使用者独立访谈、首次回传与续接。
