GitHub 开发流程

提案 proposal → 明确决策 → FullSpec / MiniSpec → 关联 Issue 的实现 PR → 验收 → 用户文档。Proposal-Accepted 需要明确决定；Documented 只表示已实现功能的用户文档完成。

首片可以使用 SQLBolt 或 SQLZoo 的具体章节作为资源候选；需要分别核验语言、前置与访问条件。链接能打开不等于已验证适合用户。
