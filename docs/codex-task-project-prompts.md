# 可复制的任务拆解与持续协作提示词

把方括号中的内容替换成自己的信息。资料只填写你愿意让当前对话读取的范围。以下提示词是协作约定，不会自动创建客户端未支持的 Project、持续监测或跨设备同步。

## A. 收集所有事情

```text
我想先和你聊清楚现在要做的事情，再找到可以开始的方法。
请读取我指定的资料：[本地笔记或文件]，不要扫描其他私人目录。
我还会继续补充，不要因为资料暂时不全就替我补造事实。

先整理正在做、拖着没做、想做、担心忘记的事情。
保留我的原意，区分确定期限、估计期限和未知；找出今天的紧急事项。
目前稳定时间是：[时间]；已经确定的安排是：[安排或暂时没有]。
只问影响今天行动的关键问题，先让我能开始一件事。
计划可以先作为建议，激活或改动安排前把具体结果给我核对。
```

## B. 拆任务、组织对话与 Project

```text
请先检查现有项目和对话，复用合适的持续入口。
为我的事项建立稳定任务编号，给出目标、输入、产物、验收、负责人、
期限、状态、下一步和实际进展；未知内容明确标出。

我授权你为以下方向创建独立对话：[方向列表]。
新对话先读取明确的交接文件，只确认范围并等待我继续，不同时启动长期任务。
按共同资料和目标建议 Project，按任务上下文拆对话；客户端没有相应创建工具时，
明确告诉我，并先用有名字的侧边栏分组。不要把分组说成已创建的 Project。
总览保留优先级和时间冲突，每个任务对话只维护本任务。
整理侧边栏可以移动和命名；不删除记录，不归档仍在进行的工作。
```

## C. 新任务对话的交接首条消息

```text
这是 [任务 ID｜标题] 的持续对话。
目标：[目标]；我的当前基础：[本人确认的信息]。
允许读取：[资料位置]；共享清单：[事实来源位置]。
已发生的结果：[结果和依据]；尚未确定：[未知事项]。
下一步：[一次具体行动]；产物与验收：[如何判断完成]。
时间边界：[预算、确定期限和估计期限]。

你只负责此任务。不要改其他任务或重新安排我的全部时间。
先读交接并简短确认，然后等待我继续。
完成实际行动后，回传结果、提示程度、证据、耗时和下一步。
读取最新清单再更新自己的字段；发生版本冲突时合并，不能覆盖别人更新。
AI 产物、活动记录和本人独立结果分别记录，不能互相替代。
当前进展保持简短；旧过程先存历史，当前摘要不无限追加。
```

## D. 开始一次行动

```text
今天推进 [任务 ID]，我有 [时间]。
请根据最新进展选一个能在这段时间内完成的动作，写清产物和验收。
如果是学习，先让我尝试，按卡点给最少必要提示，不先给整份答案。
如果是开发，先检查已有能力和正在进行的实现，保留他人改动。
推进到有可核验结果，然后记录真实完成范围和剩余问题。
```

## E. 完成后回传

```text
请先核对这次实际发生了什么，再更新 [任务 ID]。
记录：本人做了什么、留下的产物、使用了多少提示、验证结果、
证据位置、实际耗时、尚未完成的范围、下一步。
不要把“看过”“AI 写好了”“界面动了”登记成本人掌握或整个目标完成。
若只能给出回传内容，明确说明尚未写入共享清单。
保存历史后，当前摘要只保留最新结果、卡点和下一步，引用详细产物位置。
```

## F. 卡住时调整

```text
我在 [具体步骤] 卡住了。先结合我的尝试和实际结果找原因，
区分前置知识、任务大小、资料、时间和意愿，不直接给我贴标签。
给一个更小的下一步，说明怎样验证它是否解决了卡点。
若需要改变原安排，展示具体变更和影响，等我核对后再生效。
```

## G. 成熟过程公开沉淀

```text
把这次形成的通用方法沉淀到我指定的 GitHub 仓库：[仓库]。
先核对账号、仓库归属、已有文档和正在进行的相关工作。
公开材料包含：问题、实际改动、验证证据、未完成范围、可复制提示词和虚构示例。
私人原始资料留在本机；不能复制我的笔记、真实对话、私人记忆、
任务数据库、简历、账户或包含身份信息的截图。
提交前检查 diff、密钥、凭证、身份文字和 Git 元数据。
通过关联 Issue 的文档 PR 交付，明确已发布分支与已合并 main 的区别。
```

## H. 保存当前阶段，防止上下文膨胀

```text
请为当前任务保存短交接，使用 task-checkpoint 模板。
读取最新清单和相关依据；保留目标、最新结果、帮助程度、未知、约束、
一个下一步、验收及必要资料位置。注明更新时间、来源版本和负责人。
旧阶段过程保存到历史或使用现有版本历史，不复制整段聊天，不硬截断约束。
只更新本任务；不能修改其他任务的进展或改变我的安排。
先在原对话继续，只有我明确要求时才创建新阶段对话。
```

## I. 从交接恢复，核对后再推进

```text
继续 [任务编号]。读取 [当前交接路径] 和它指定的最新总清单。
仅按需读取引用资料，不扫描全部旧聊天或私人目录。
先简短复述目标、已完成、未知、约束和下一步，说明交接是否过期。
冲突时核对依据；缺关键事实先问，不假装共享了其他对话记忆。
本次允许推进的范围：[范围]；时间：[时间]。
有实际结果才更新短进展，旧结果保留在历史。
```

进度查看优先读取短清单；只有遗漏或冲突才读取对应对话。自动定时检查需要另外设置并授权，不由这些提示词启动。详见[长对话与进度回传协议](codex-context-management.md)。
