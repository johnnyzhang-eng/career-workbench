# 虚构示例：课程、求职和作品如何同时保留

这是为教学编写的虚构情境，不是任何人的真实日程、能力或任务记录。

一位同学想准备数据库课程测验、了解实习岗位、继续做作品网站，也想坚持阅读。测验在两周后，其他事项尚无确定期限；本人稳定能用 90 分钟，偶尔有更多时间。总览先确认今天没有其他必须处理的事，再提出先做一次课程练习；额外时间尚未提前占满。

## 初始清单

| ID | 持续方向 / 对话 | 今天的下一步 | 状态 / 验收 |
| --- | --- | --- | --- |
| T01 | 学习 / 数据库练习 | 写一条筛选查询并逐句解释 | 进行中；运行结果正确且本人能解释 |
| T02 | 求职 / 实习资料 | 留待后续选一条官方具体岗位核验 | 待推进；链接和资格要求有来源 |
| T03 | 作品项目 / 网站开发 | 留待后续复现一项导航问题 | 待推进；复现记录及修复验证 |
| T04 | 阅读 / 理解笔记 | 有余量时解释一个观点和例子 | 待推进；自己的解释与疑问 |

同学授权创建四个持续对话。各对话读取自己的交接后等待；不会因对话创建完成，就把四件事都登记成“正在执行”。学习材料、作品仓库分别放在自己的资料范围内，侧边栏分组只负责让它们容易找到。

## 第一次行动的回传

本人尝试查询后漏了一个条件。在一次提示后修正，运行结果正确，能解释各子句。

```text
T01：进行中
实际进展：一次提示后完成第一条筛选查询，运行结果符合样例。
依据：本人保存的查询、样例结果及解释。
实际耗时：25 分钟。
尚未验证：新题能否独立完成。
下一步：换一组数据，独立写查询；再解释为何不选其他行。
```

这里完成的是一次练习，并没有把整个数据库课程标成已掌握。AI 生成的参考解答可以另存为学习资料；它不是这位同学独立完成的证据。

## 第二次行动与总览

换题后本人独立完成查询，总览据实际结果更新 T01，提出下一次可以进入排序练习。若本人今天已经没有余量，T02–T04 继续保留下一步；它们不会因此被删除，也不会被错误标成失败。

工作台读到新记录后显示当前行动和最新结果。房间中的角色可以表达用户明确开始了学习，但完成条件仍由作品、解释和练习结果承担。清单只需要支持同学回答三件事：现在做什么，刚才完成到哪里，下次从哪继续。
